# מדריכי צילום — Studio Image Photography
אתר סטטי (GitHub Pages) למכירת מדריכי צילום.

## מה לערוך
כל ההגדרות בקובץ אחד: `config.js`
- `paypalEmail` — כתובת המייל של חשבון ה-PayPal שלך (אליו יגיע התשלום).
- `contactEmail` — מייל ליצירת קשר.
- `guides`: רשימת המדריכים. שלושת המדריכים הקיימים הם **דוגמה בלבד**. לכל מדריך: `title` (כותרת), `price` (מחיר בשקלים), `level` (רמה), `image` (תמונת שער מתיקיית `img/`), `short` (תיאור קצר), `description` (תיאור מלא), `topics` (מה לומדים). ה-`id` חייב להיות ייחודי ובאנגלית.
- `example: true` מציג תגית "דוגמה" קטנה על המדריך. מחק את השורה כשהמדריך אמיתי.
- תמונות: שים קבצים בתיקיית `img/` ועדכן את `image`. את תמונת הפתיחה מחליפים בקובץ `img/hero.jpg`.
- את טקסט ה"אודות" עורכים ב-`index.html` וב-`about.html`.

## הוספת מדריך
העתק בלוק `{ ... }` ברשימה, שנה את ה-`id` ואת הפרטים.

## מסירת המדריך
אחרי תשלום תקבל הודעה מ-PayPal; שלח ללקוח את קובץ המדריך ידנית במייל.
