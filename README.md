# מדריכי צילום — Studio Image Photography
אתר סטטי (GitHub Pages) למכירת מדריכי צילום.

## ניהול האתר בלי קוד (Pages CMS)
כל התוכן נמצא בקבצי נתונים, ואפשר לערוך אותו בממשק נוח:
1. נכנסים ל-https://app.pagescms.org (או לוחצים "כניסת מנהל" בתחתית האתר) ומתחברים עם GitHub.
2. בפעם הראשונה מתקינים את ה-GitHub App של Pages CMS על החשבון ומאשרים גישה למאגר `photo-guides`.
3. פותחים את המאגר. בתפריט מופיעים **הגדרות האתר**, **מדריכים** ו**ביקורות מאושרות**.
4. עורכים ולוחצים Save. כל שמירה היא commit, והאתר מתעדכן תוך כדקה.

## איפה נמצא כל דבר
- `data/site.json`: מייל PayPal, מייל ליצירת קשר, כתובת טופס הביקורות, קישור להזמנת צילום, וטקסטים ותמונות של הפתיחה, אודות וצור קשר.
- `data/guides.json`: המדריכים (שם, מזהה באנגלית, מחיר בשקלים, רמה, תמונת שער, תיאורים, נושאים, תגית "דוגמה").
- `data/reviews.json`: ביקורות שאושרו לפרסום.
- `img/`: כל התמונות. העלאת תמונה דרך Pages CMS שומרת אותה כאן.
- `.pages.yml`: הגדרת ממשק הניהול. אין צורך לגעת בו.

## תשלומים
כפתור הרכישה פותח את עמוד התשלום של PayPal עם שם המדריך והמחיר בשקלים. אחרי התשלום הלקוח מגיע לעמוד תודה. תקבל הודעה מ-PayPal, ואת המדריך שולחים ללקוח ידנית במייל.

## ביקורות לקוחות
ביקורות שנשלחות מהאתר נשמרות ב-Supabase בסטטוס "ממתינה" ולא מופיעות באתר עד שתאשר אותן.
- **ניהול:** נכנסים לכתובת `reviews-admin.html` (או "כניסת מנהל" ← "ניהול ביקורות") ומתחברים עם המייל והסיסמה שלך. שם מופיעות הביקורות שממתינות, עם כל הפרטים, ולכל אחת יש כפתורי "אישור ופרסום" ו"מחיקה". אפשר גם להסיר מהאתר ביקורת שכבר פורסמה.
- **אישור** מופיע באתר מיד, כולל עדכון הדירוג הממוצע.
- **אבטחה:** גולשים יכולים רק לשלוח ביקורת ממתינה ולקרוא ביקורות שאושרו. רק משתמש שמופיע ברשימת המנהלים יכול לאשר או למחוק. הרשמה פתוחה כבויה. המפתח שבקובץ `data/site.json` הוא מפתח ציבורי, וזה תקין.
- **שכחת סיסמה:** בדף ההתחברות לוחצים "שכחתי סיסמה" ומקבלים קישור למייל.
- **שמירה על פעילות:** תהליך אוטומטי ב-GitHub Actions (`.github/workflows/keepalive.yml`) פונה ל-Supabase פעם ביום, כדי שהפרויקט החינמי לא יושהה.

## קביעת פגישות
- **ללקוחות:** `booking.html`. בוחרים שירות, תאריך ושעה פנויים (מוצגים רק מועדים פנויים) וממלאים פרטים. הבקשה נשמרת כ"ממתינה" והמועד נתפס עד להחלטה שלך. על כל בקשה חדשה נשלח אליך מייל (FormSubmit).
- **ניהול:** `bookings-admin.html`, עם אותה התחברות של ניהול הביקורות. יש לשוניות ממתינות, מאושרות ונדחו. "אישור + וואטסאפ" או "דחייה + וואטסאפ" שומרים את ההחלטה ופותחים וואטסאפ ללקוח עם הודעה מוכנה, ונשאר רק ללחוץ שליחה. דחייה משחררת את המועד.
- **זמינות והגדרות:** שעות פעילות לכל יום בשבוע, אורך משבצת, התראה מינימלית, כמה ימים קדימה, חסימת תאריכים או שעות, וניהול שירותים (שם, משך, פעיל או לא).
- **אבטחה:** גולשים יכולים רק לראות שעות פנויות ולשלוח בקשה דרך פונקציה מאובטחת. פרטי לקוחות אחרים אינם נגישים. אי אפשר לקבוע שתי פגישות חופפות (אכיפה במסד הנתונים), ויש הגבלה של עד 3 בקשות ממתינות לכל טלפון. הגדרות המסד נמצאות ב-`supabase/bookings.sql`.
